Separating run contracts from visual surfaces

Run lifecycle overview

Every run moves through explicit stages from draft through complete while keeping write and destructive effects behind owner confirmation.

Note

Warning

Scope boundary

Write-effect and destructive tools pause at waiting_for_owner even when invoked from a precompiled portal scaffold.

Run endpoint reference

Lifecycle routes

  • POST /v1/runs
    effect · write

    Start a contract run; write-effect tool steps pause at waiting_for_owner.

  • GET /v1/runs/:run_id
    effect · read

    Inspect run stage, elapsed latency, and immutable evidence receipts.

  • DELETE /v1/runs/:run_id
    effect · destructive

    Halt execution and drop scratch state while preserving the audit ledger.
