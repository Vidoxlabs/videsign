Harness run API · endpoint reference

Run lifecycle routes

Every route pairs a protocol method with an effect class; the effect label travels with the row, never carried by colour alone.

  • POST /v1/runs
    effect · write

    Create a run from a stored contract; write-effect tools pause at the owner gate.

    contract_id string · required scratch boolean
  • GET /v1/runs/:run_id
    effect · read

    Read the run's lifecycle state, current stage and receipt links.

    run_id string · path · required
  • DELETE /v1/runs/:run_id
    effect · destructive

    Stop a run and drop its scratch state; the run receipt stays queryable.

    run_id string · path · required
  • POST /v1/runs/:run_id/credentials
    effect · credential

    Bind a scope-limited credential to the run; the secret value is never returned.

    run_id string · path · required scope string · required
